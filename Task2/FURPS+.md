| Код | Требования                                            | Комментарий  |
|-----|-------------------------------------------------------|--------------|
| F   | Функциональные (Functionality)                        |              |
| F01 | Сайт. Клиент видит список доступных депозитов         |              |
|     |  с актуальными ставками                               |              |
| F02 | Клиент может подать заявку на депозит оставив свой    |              |
|     | номер телефона и Ф.И.О.                               |              |
| F03 | Заявка клиента с сайта обработана менеджером          |              |
|     | кол-центра в системе.                                 |              |
| F04 | В интернет-банке клиент видит список доступных депо-  |              |
|     | зитов с актуальными ставками                          |              |
| F05 | В интернет-банке клиент видит список доступных депо-  |              |
|     | зитов с персонализированными ставками                 |              |
| F06 | Клиент может подать заявку на открытие депозита       |              |
|     | указав: счет и сумму депозита. Операция               |              |
|     | подтверждается с помощью СМС-кода.                    |              |
| F07 | Клиент получает СМС-уведомление после подтверждения   |              |
|     | размера ставки и открытия депозита менеджером бэк-    |              |
|     | офиса. Актуально для MVP.                             |              |
| F08 | Данные в интернет-банке должны шифроваться при        |              |
|     | передаче.                                             |              |
|     |                                                       |              |
|     |                                                       |              |
| U   | Удобство использования (Usability)                    |              |
| U01 | Интерфейс платформы должен соответствовать интерфейсу |              |
|     | и системы дизайна для приложений, которая принята     |              |
|     | в компании. Включая привычные цвета и брендированные  |              |
|     | элементы.                                             |              |
|     |                                                       |              |
|     |                                                       |              |
| R   | Надёжность (Reliability)                              |              |
| R01 | Доступность (availability) системы на уровне 99,9%    |              |
|     |                                                       |              |
|     |                                                       |              |
| P   | Производительность (Performance)                      |              |
| P01 | Загрузка страницы не более 1 секунды.                 |              |
| P02 | Выполнение операций должно быть не больше 1 секунды.  |              |
| P03 | Подгрузка справочных данных меньше секунды            |              |
| P04 | Предусмотреть равномерное горизонтальное              |              |
|     | масштабирование и распределение запросов между        |              |
|     | серверами, приложениями и ЦОД.                        |              |
|     |                                                       |              |
|     |                                                       |              |
| S   | Поддерживаемость (Supportability)                     |              |
| S01 | Создание документации на разрабатываемую              |              |
|     | функциональность для дальнейшего расширения системы.  |              |
|     |                                                       |              |
|     |                                                       |              |
| +R  | + Ограничения (Restrictions)                          |              |
| +R01| Работа с СМС должна быть реализована силами команды   |              |
|     | разработки банка.                                     |              |
| +R02| Разработать функционал работы со ставками по          |              |
|     | депозитам в АБС.                                      |              |
| +R03| Использовать технологии которые уже есть в банке,     |              |
|     | например MSSql, Oracle.                               |              |
| +R04| Учитывать экспертизу сотрудников хотя бы на уровне    |              |
|     | языков программирования.                              |              |
| +R05| Новые технологии должны быть совместимы               |              |
|     | с существующими платформами разработки.               |              |
| +R06| Для очереди сообщений лучше использовать Kafka. Хотя  |              |
|     | она и несовместима с текущей версией платформы        |              |
|     | интернет-банка.                                       |              |
| +R07| Микросервисная архитектура для задачи открытия        |              |
|     | депозитов.                                            |              |
| +R08| Нужно избежать работы напрямую через API АБС из-за    |              |
|     | перегрузки БД системы АБС.                            |              |
| +R09| АБС может массштабироваться только вертикально.       |              |
| +R10| При сбое в ЦОД система должна продолжать работать     |              |
|     | в РЦОД                                                |              |
